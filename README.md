# ROM Lab — Cruzadinha de Arquitetura Computacional

Jogo em HTML, CSS e JavaScript puros com três desafios sobre 16 termos da disciplina.

**Site publicado:** [https://kaiky-clementino.github.io/ROM-LAB/](https://kaiky-clementino.github.io/ROM-LAB/)

## Como jogar

### Cruzadinha:
- clique em uma casa ou pista e digite. Setas navegam, espaço alterna horizontal/vertical, Backspace apaga, Enter confere. O botão **Conferir** marca as palavras certas (verde) e erradas (vermelho) e atualiza o contador "X de 16 palavras". Cada conferência com erro grava 20 KB na ROM, que não apaga: com 100 KB a ROM enche e o jogo termina. **Reiniciar** limpa o tabuleiro.

### Gravador de ROM:
- descubra a palavra por letras (teclado ou tela) ou digite a palavra inteira. Cada erro grava 20 KB; no quinto a ROM enche.
  
### Cache Embaralhado:
- monte a palavra com as peças embaralhadas e clique em **Conferir**.
